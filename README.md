これはAutoRowsというWindowsアプリです。

AutoRowsは、OS上のさまざまな操作を自動化するためのアプリケーションです。

まだ色々足りない機能も多いと思いますが、何かの役に立てばと思い公開します。

ご意見・ご要望もお待ちしております。

## 

以下の環境で開発・テストしました。
- Windows 11
- Visual Studio 2022
- .NET Framework 4.7.2

## 

●インストール方法●

画面右上の「Code」ボタンより「Download ZIP」を選択。
ダウンロードしたZIPファイルを展開。
更に その中にあるZIPファイルを好きなフォルダに展開。

## 

●実行方法●

展開後の AutoRows\AutoRows\bin フォルダにある AutoRows.exe を実行。
